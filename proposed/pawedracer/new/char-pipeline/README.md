# char-pipeline (proposed factory tool)
Zero-dependency, offline character-from-text pipeline: bible schema, prompt composer (4 styles x 4 shots), adapter interface (mock only; network adapters refused without approval), reference learning (baseline-JPEG/PNG decode, palette, bg removal), post-process, consistency check, contact sheet, export to an asset library via the factory library ops. See `bin/char.mjs` (no args prints usage). Copy to `factory-core/tools/char-pipeline/`; the test imports are relative to the pawedracer layout (`tools/character-pipeline/`), adjust the path prefix. Set FACTORY_LIBRARY_CLI if the library CLI is elsewhere.
