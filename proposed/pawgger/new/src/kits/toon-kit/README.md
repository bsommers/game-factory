# toon-kit
`toonKit(painterKit)` wraps painter-kit so an existing painterly art module draws flat cartoon instead: gradients -> middle-stop flat colour, soft shadows -> flat ellipse, dark strokes -> thick #1a1a1a, grain removed. Same geometry/names/frames. `toonCtx(ctx)` wraps any Canvas2D ctx. Needs painter-kit. Test: Pawgger test/art-toon.test.mjs ("toon kit").
