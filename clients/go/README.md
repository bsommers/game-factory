# factory-client (Go)

Typed thin client for the game-factory HTTP API: one method per capability (104), the `{ok,data,error,next}` envelope, stable `Err*` code constants, and an SSE progress stream. Standard library only (`net/http`, `encoding/json`). Generated by `factory clients generate --lang go`; do not edit by hand (a drift test fails if you do).

```go
c := factoryclient.New("")                       // http://127.0.0.1:4790, 30s timeout
env, err := c.KitsList(ctx, factoryclient.KitsListInput{})
var ae *factoryclient.Error
if errors.As(err, &ae) && ae.Code == factoryclient.ErrNotFound { /* ... */ }
var data struct{ Kits []map[string]any }
_ = env.Decode(&data)

evs, errs := c.Events(ctx, "/path/to/project", "") // SSE: GET /events?project=
for e := range evs { fmt.Println(e.Name, string(e.Data)) }
```

Required input fields are plain values, optional ones are pointers or omitted slices/maps. `Call(ctx, name, map)` reaches any capability, including ones newer than this client. Start the server with `bin/factory serve` (127.0.0.1 only).

Test: `go vet ./... && go test ./...` (the live smoke test runs when `FACTORY_URL` is set).
