# factory-client (Rust)

Typed thin client for the game-factory HTTP API: one method per capability (50), the `{ok,data,error,next}` envelope, stable `codes::*` constants, and an SSE progress iterator. Generated by `factory clients generate --lang rust`; do not edit by hand (a drift test fails if you do).

Dependencies: `serde_json` only. HTTP is plain HTTP/1.0 over `std::net::TcpStream`, which is enough because the server is loopback-only and plain http; `ureq` pulls a TLS stack for no gain here. Blocking API.

```rust
use factory_client::*;
let c = Client::new(None)?;                       // http://127.0.0.1:4790, 30s timeout
let env = c.kits_list(&KitsListInput::default())?;
match c.styles_show(&StylesShowInput { id: "nope".into(), ..Default::default() }) {
    Err(e) if e.code == codes::NOT_FOUND => {}
    _ => {}
}
for ev in c.events("/path/to/project", None)? { println!("{:?}", ev?); }
```

Input structs derive `Default` (required fields default to empty). `call(name, &json)` reaches any capability. Start the server with `bin/factory serve` (127.0.0.1 only).

Test: `CARGO_TARGET_DIR=/datanapps/cargo-target/clients cargo test` (the live smoke test runs when `FACTORY_URL` is set).
