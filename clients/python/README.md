# factory-client (Python)

Typed thin client for the game-factory HTTP API: one method per capability (99), the `{ok,data,error,next}` envelope, stable `codes.*` constants, and an SSE progress generator. Standard library only (`urllib`). Generated by `factory clients generate --lang python`; do not edit by hand (a drift test fails if you do).

```python
from factory_client import Client, FactoryError, codes
c = Client()                                      # http://127.0.0.1:4790, 30s timeout
env = c.kits_list()                               # Envelope(ok, data, error, next)
try:
    c.styles_show(id="nope")
except FactoryError as e:
    assert e.code == codes.NOT_FOUND
for ev in c.events("/path/to/project"):           # SSE: GET /events?project=
    print(ev.name, ev.data)
```

Keyword arguments are the capability input (`None` is dropped; a parameter named like a Python keyword gets a trailing underscore). `call(name, dict)` reaches any capability. Start the server with `bin/factory serve` (127.0.0.1 only).

Test: `python3 -I -m unittest` from this directory (the live smoke test runs when `FACTORY_URL` is set).
