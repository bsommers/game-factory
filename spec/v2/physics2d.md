# physics2d spec (v2)

Reference: `templates/web-project/src/lib/physics2d.js` (builds on collision2d; port that first, see `collision2d.md`). Vectors: `spec/v2/vectors/physics2d.json` (`node spec/v2/gen-vectors.mjs [--check]`). Tolerance: ids, step numbers, event types/order, contact counts, `mode`, `asleep`, `key` exact; floats abs/rel 1e-9. This is an iterative solver over fixed-step sequences, so the port must reproduce the **exact order of floating-point operations and iteration** below; reordering sums or solver loops will drift past 1e-9 within tens of steps. Fully deterministic: no clocks, no RNG, ids count up from 1, bodies iterate in id order. Same conventions as collision2d: x right, y DOWN, angles radians (positive clockwise on screen), px/seconds.

## Vector ops
**sim** (default; world runner) input `{config, bodies, joints, steps, dt=1/60, impulses[{step,id,ix,iy}], kinematic[{step,id,vx,vy,w=0}], checkpoints (default [steps])}`. Run: `createWorld(config)`, `addBody` each (ids 1..n), `addJoint` each; for step `s=1..steps`: apply impulses with `step==s` (`applyImpulse(id,ix,iy)`, no point), then kinematic (`kinematicStep`), then `step(dt)`; every event in `world.events` is appended as `{step:s,...event}`; at checkpoint steps push `{step, bodies:[{id,x,y,angle,vx,vy,w,asleep}]}`. Output `{states, events, contacts}` where `contacts` = final `world.contacts` reduced to `{key, points: count, jn: [per-point normal impulse]}`.
**character** input `{map | colliders, cfg, body:{x,y,mode?}, script:[{dx,dy,n,jp}]}`: scene = `createTilemap(map)` or `createScene(colliders)`; character `makeCharacter(x,y)` (+`mode` override); config `makeCharConfig(cfg)` with `emit` recording `{n: name, step}` where `step` is the 0-based index of the emitting tick (the counter is incremented after `stepCharacter` returns). Each segment runs `n` ticks of `stepCharacter(b,{dx,dy,jumpPressed: jp && k===0},1/60,scene,cfg)`; after each segment push `{step (cumulative ticks), x,y,vx,vy,mode}`. Output `{states, events}`.

## World
Defaults: gravity `{0,600}`, velocityIterations 10, slop 0.25, baumgarte 0.2, maxBias 150, restitutionThreshold 30, warmRadius 4, cellSize 64, sleep true, ccd true, timeToSleep 0.5, linearSleep 5, angularSleep 0.1. `config.gravity` merges per-component.

**addBody(def)** returns id. Defaults: type `dynamic`, x/y/angle/vx/vy/w 0, density 1, friction 0.5, restitution 0, layer 1, mask -1, sensor false, linearDamping/angularDamping 0, gravityScale 1, fixedRotation false, allowSleep true. Shape required (throws). Shapes: `circle{r}`, `box{hw,hh}`, `capsule{hl,r}`, `polygon{points}`. Polygon: points copied, centroid `(cx,cy)` computed (shoelace, signed-area aware), body position += centroid rotated by `angle`, points re-centred. Mass (dynamic only; static/kinematic have invMass 0, invI 0): circle `m=d*pi*r^2`, `I=.5*m*r^2`; box `m=d*4*hw*hh`, `I=m*(4hw^2+4hh^2)/12`; capsule `mr=d*4*hl*r` (rectangle), `mc=d*pi*r^2`, `dd=4r/(3pi)`, `hm=mc/2`, `Ir=mr*(4hl^2+4r^2)/12`, `Ih=.5*hm*r^2-hm*dd^2+hm*(hl+dd)^2`, `m=mr+mc`, `I=Ir+2*Ih`; polygon `m=d*area`, `I=d*I_centroid`. `invMass = m>0?1/m:0`; `invI = fixedRotation||I<=0 ? 0 : 1/I`. Placed shape (collision2d): circle; box -> `aabb` when `angle===0` (exact) else `obb`; capsule; polygon.
**removeBody** drops joints/contacts of the id. **addJoint** `{type:'distance'|'spring'|'revolute', a, b, anchorA, anchorB (body-local, default 0,0), length, stiffness (spring default 200, else 0), damping 0, collideConnected false}`; missing bodies throw; non-revolute with undefined `length` takes the current anchor distance; wakes both bodies. Control: `wake`, `setVelocity`, `setPosition`, `applyForce`, `applyTorque` (all wake the body), `applyImpulse(id,ix,iy,px?,py?)` (`v += i*invMass`; `w += invI*cross(p-pos,i)` only if a point is given), `kinematicStep(id,vx,vy,w=0)` sets velocities (no wake). Errors on unknown id: `physics2d: no body <id>`.

## step(dt) (exact order)
1. **Integrate velocities** over bodies in id order; non-dynamic or asleep: zero force/torque, skip. `v += (g*gravityScale + f*invMass)*dt`, `w += torque*invI*dt`; then damping `v /= 1+dt*linearDamping`, `w /= 1+dt*angularDamping`; clear forces.
2. **Broadphase**: new spatial hash (cellSize), each body's `bounds(placed)` expanded by `margin=2*slop`; `hash.pairs()` (sorted pairs by id). Per pair `(ia,ib)` (ia<ib): both sensors -> skip; sensor pair skipped if both static, solid pair skipped if neither dynamic; skip joint-connected pairs unless `collideConnected` (key `lo:hi`); a solid pair whose bodies are both "settled" (static, asleep, or kinematic with zero velocities) reuses the previous contact with `carried:true` (no re-collision); else `collide(placed A, placed B)`; none -> skip. Sensor hit -> record `{key,sensor,other}` (`sensor` is the sensor's id), no response. Otherwise wake an asleep body if the other is awake (awake = dynamic non-asleep, or kinematic that is not settled), then build contact: normal = manifold normal (a->b), `friction=sqrt(fA*fB)`, `restitution=max`, points with warm start: for each new point find the previous-step contact (same key) point with nearest squared distance `< warmRadius^2` (strict, first minimum wins) and copy its `jn,jt`; else 0.
3. **Events** (after narrowphase, before solving): contact keys vs previous step: `begin{a,b}` for contacts new this step in contact order, then `end{a,b}` for previous contacts that vanished in previous-order; then sensor events: `enter` (new key) or `stay` per current sensor in order, then `exit` for vanished ones. Sensor events `{type,sensor,other}`. `world.events` is reset every step; `onEvent` called after the step.
4. **Pre-solve** over non-carried contacts: tangent `t=(ny,-nx)`; per point `ra=p-A.pos`, `rb=p-B.pos`; `kN=iA.mass+iB.mass+A.invI*cross(ra,n)^2+B.invI*cross(rb,n)^2`, `massN=kN>0?1/kN:0` (same for tangent); relative velocity `dv=(B.v - B.w*rb_perp...)`: `dvx=(B.vx-B.w*rby)-(A.vx-A.w*ray)`, `dvy=(B.vy+B.w*rbx)-(A.vy+A.w*rax)`, `vn=dv.n`; `biasR = vn < -restitutionThreshold ? -e*vn : 0`; `biasP = min(maxBias, max(0, depth-slop)*baumgarte/dt)`; `bias=max(biasR,biasP)`; apply warm-start impulse `jn*n + jt*t` (A with -1, B with +1; `applyP: v += p*invMass*k; w += invI*cross(r,p)*k`). Then wake joint partners as for contacts; `jlive` = joints not between two settled bodies; `prestepJoint` each (computes world anchors `r = rot(local)`, `d = pB+rb-pA-ra`; revolute: effective mass matrix `m11,m12,m22` from the 2x2 K (inverse via `det`, 0 when det 0), `bias = d*baumgarte/dt`; distance/spring: `u=d/|d|` (`(1,0)` if len 0), `C=len-length`, `k` as above, soft when `stiffness>0`: `gamma=1/(dt*(damping+dt*stiffness))`, `bias=C*dt*stiffness*gamma`, else `gamma=0, bias=C*baumgarte/dt`; `mass=1/(k+gamma)` if positive else 0; warm-apply accumulated joint impulse).
5. **Velocity iterations** `velocityIterations` times: all live joints in order (revolute: `i = M*-(cdot + bias)`, accumulate, apply; linear: `imp=-mass*(cdot.u + bias + gamma*j)`, accumulate), then each contact in order: for all points friction first (`lam=-massT*dv.t`, clamp accumulated `jt` to `+-friction*jn`), then for all points normal (`lam=-massN*(dv.n - bias)`, accumulated `jn` clamped `>=0`).
6. **Integrate positions** (id order; skip static/asleep): `m = v*dt`; for dynamic non-sensor bodies with `ccd`, `ccdFraction`: `d=|m|`; if `d <= 0.5*minDim` (`minDim=min(bounds w,h)/2`) -> 1; else among static non-sensor bodies passing `canCollide` and swept-bounds overlap, `shapeCast(placed,m,placedStatic)`; keep non-`overlap` hit with smallest `t` (strict, only if `<1`); on hit, if `v.normal<0` reflect velocity `v -= (1+e)*vn*n` with `e = max(restitutions)` only when `-vn > restitutionThreshold` else 0; fraction `t*(1-1e-6)`. Then `x+=mx, y+=my, angle += w*dt` (kinematic bodies move too).
7. **Sleep** (when `sleep`): over awake dynamic bodies build islands by union-find (root = smaller index) across solved contacts and live joints; a body is still when `allowSleep` and `|v|^2 < linearSleep^2` and `w^2 < angularSleep^2`, `sleepT` accumulates `dt` or resets to 0; island sleeps when its min `sleepT >= timeToSleep`: members `asleep=true`, island id from a counter (1..), velocities zeroed. Wake clears the whole island.
8. Store contacts (`key,a,b,nx,ny,friction,restitution,points{x,y,depth,jn,jt}`), sensors, `time += dt`, `steps++`.
Also: `energy()`, `raycast(ox,oy,dx,dy,maxT=1,{includeSensors,layer,mask})` (nearest `t`, ties lowest id, result `{body,...hit}`), `queryAABB(bounds)`, `queryPoint(x,y)` (id order), `snapshot()`/`restore(s)` (deep copy of bodies, joints, contacts incl. warm-start impulses, sleep timers, counters, config; a restored world replays bit-identically; clears events).

## Character controller
`CHAR_DEFAULTS`: gravity 520, jumpV 200, runSpeed 60, airSpeed 60, airAccel 160, hitW 8, hitH 16, stepHeight 4, snapDist 4, maxFall 1000, dropTime 0.25. `makeCharacter(x=0,y=0)` -> `{x,y,vx:0,vy:0,face:1,mode:'ground',layer:0,onPlatform:null,landed:true,t:0,dropT:0,ground:null}` (feet-anchored: box spans `y-hitH..y`, `hw=hitW/2`). `emit(name, body, extra)` called via `cfg.emit`: `jump`, `hardland` (impact vy > 140), `land` (extra = ground collider).

**stepCharacter(b,{dx,dy,jumpPressed},dt,world,cfg)**: `t+=dt`; `dropT>0` -> `dropT-=dt`; `dx|0`, `dy|0` (ints, up negative); `dx!=0` sets `face`. `wasGround = mode==='ground'`. If grounded: `jumpPressed && dy>0 && ground is oneway` -> `dropT=dropTime, vy=0, vx=dx*runSpeed, wasGround=false`; else `jumpPressed` -> `vy=-jumpV, vx=dx*airSpeed, mode 'air', landed false, ground/onPlatform null`, emit `jump`, **return without moving**; else `vx=dx*runSpeed, vy=0`. If airborne: `dx!=0` moves `vx` toward `dx*airSpeed` by `airAccel*dt` (clamped, no overshoot); `vy = min(maxFall, vy+gravity*dt)`. Then `impact=vy`, `moveCharacter(b, vx*dt, vy*dt, ...)`; if resulting mode is ground and (was air or not wasGround): emit `hardland` when `impact>140`, then `land`.
**moveCharacter**: horizontal: `n = clamp(ceil(|dx|/hw), 1, 256)` sub-steps of `sx=dx/n`; per sub-step `x+=sx`, `cs=world.query({minX:x-hw-m,maxX:x+hw+m,minY:y-hitH-m,maxY:y+m})` with `m=|sx|+stepHeight`. For each `solid` overlapping the body box (strict open-interval overlap on both axes): `rise=y-c.minY`; if (`wasGround||landed`) and `0<rise<=stepHeight` and no other solid overlaps the box raised by `rise` -> `y-=rise` (step up); else push out (`x = sx>0 ? c.minX-hw : c.maxX+hw`, `vx=0`). For each `slope` with `x` in `[minX,maxX]`: `s=surfaceY`; if `y>s && y-hitH<c.maxY`: `grad=|y1-y0|/(x1-x0)`; if `y-s <= |sx|*grad+1e-4` snap `y=s, landed, ground=c` else treat as wall. Vertical (`prevY=y`, `q` margin `|dy|+snapDist+1`): `dy<0`: nearest ceiling among non-oneway colliders (slope uses `x` in span, others open overlap) with `prevY-hitH >= c.maxY-1e-6 && prevY+dy-hitH < c.maxY`, highest `maxY` wins; hit -> `y=cl+hitH, vy=0`, else `y=prevY+dy`; `landed=false, ground=null` when rising. `dy>=0`: `findSupport(cs,b,hw,dy)` = lowest `s` (strict `<`, first wins) among colliders with `s >= y-1e-6` and `s <= y+maxDrop+1e-9` (oneway skipped while `dropT>0`; slope needs `x` within `[minX,maxX]` and uses `surfaceY`; others open overlap of `[x-hw,x+hw]` and `[minX,maxX]`, `s=minY`); hit -> `y=s, landed, ground`; else `y=prevY+dy`. Ground snap: not landed, `wasGround`, `vy>=0` -> `findSupport` within `snapDist`. Finish: `landed`, `ground` stored; `onPlatform = ground.kind==='oneway' ? (ground.id ?? ground) : null`; landed -> `vy=0, mode 'ground'` else `mode 'air'`.

## Edge cases
Sensor-vs-sensor and static-vs-static never interact; kinematic bodies are never pushed but carry dynamic ones via friction; sleeping bodies woken by awake contacts/joints/setters; `polygon` bodies recentred (reported x,y is the centroid); restitution only above the threshold; joint `length` default from initial anchors; zero-length joint direction `(1,0)`; character `dx|0` truncates; slope walls vs ramps by `grad`.

## Determinism
Fixed `dt`, id-ordered iteration, pairs sorted by id (numbers before strings), solver order friction-then-normal per contact then contacts in broadphase order, warm start by nearest-point match. A port that matches the vectors at 1e-9 over all checkpoints is conformant; never loosen the tolerance or drop cases to pass.
