# collision2d spec (v2)

Reference: `templates/web-project/src/lib/collision2d.js`. Vectors: `spec/v2/vectors/collision2d.json` (`node spec/v2/gen-vectors.mjs [--check]`; file is `{engine, version: 2, cases: [{name, input, expect}]}`). Tolerance: ints (indices, ids, counts, col/row, array lengths and order) and booleans/strings/`null`-vs-non-null exact; every float abs/rel 1e-9. The generator normalises `-0` to `0` and keys to sorted order; ports compare numerically, not textually.

Conventions: **x right, y DOWN**. Angles radians, rotation `x'=x*cos-y*sin, y'=x*sin+y*cos` (positive = clockwise on screen). Plain data, pure functions, no clocks/randomness. `EPS = 1e-9`. Shape position = centre. Shapes: `{type:'aabb',x,y,hw,hh}`, `{type:'circle',x,y,r}`, `{type:'obb',x,y,hw,hh,angle}`, `{type:'polygon',x,y,angle,points:[{x,y}]}` (convex, local points, any winding), `{type:'capsule',x,y,hl,r,angle}` (segment of half length `hl` along local x, swept by `r`). Missing `angle` = 0. Unknown type throws.

Hull (internal, but all behaviour is defined on it): `{v:[pts], r}` in world space. circle = 1 vertex + r; capsule = 2 vertices (centre -/+ hl*(cos,sin)) + r; aabb = 4 vertices (-,-),(+,-),(+,+),(-,+); obb = same corners rotated; polygon = rotated points. Polygon/obb winding is normalised so `area2 >= 0` (reverse the vertex list when the shoelace sum is negative); outward normal of edge e is `(ey,-ex)/|e|`. Faces list: one per non-zero edge in vertex order `i`; a 2-vertex hull (capsule) additionally gets two end-cap axes (`+dir` at vertex b, `-dir` at vertex a, `i=-1`) after the edge faces; a 1-vertex hull has no faces. Never sort or reorder beyond this: tie-breaks depend on it.

Manifold `{normal, depth, points:[{x,y,depth}]}`: unit normal points from a TOWARD b; moving b by `+normal*depth` separates. 1 or 2 world points. Touching (depth 0) is not a collision (`null`).

## Functions (vector `op` in bold)

- **bounds**(shape): `{minX,minY,maxX,maxY}`; aabb/circle direct; others from hull vertices expanded by `r`. `boundsOverlap` is inclusive (`<=`). `canCollide(a,b)`: `(a.layer??1)&(b.mask??-1)` nonzero and `(b.layer??1)&(a.mask??-1)` nonzero (32-bit int AND; default mask = all bits). `aabbFromBounds`, `translate` (copy with x,y shifted), shape factories (`angle` default 0).
- **collide**(a,b) -> manifold|null. aabb-vs-aabb is exact: `ox=a.hw+b.hw-|dx|`, `oy` likewise, `dx=b.x-a.x`; null if `ox<=0||oy<=0`; if `ox<oy` normal `(dx<0?-1:1,0)` (so ties prefer **y**; identical boxes give normal `(0,1)`), depth `ox`, two points `(xmid,y0),(xmid,y1)` (overlap-interval ends, x midpoint) each with the depth; else normal `(0,dy<0?-1:1)`, points `(x0,ym),(x1,ym)`. Everything else: SAT over A faces then B faces (`best` = max over faces of min dot of the other hull; B's face wins only if `s > best + EPS`, so A and lower index win ties; `fromA` records the winner). If hulls separated (`best>0`, or no faces at all) -> if both `r==0` and faces exist return null; else closest pair (brute force vertex-vs-edge; A vertices vs B edges first, then B vertices vs A edges; strict `<` so first minimum wins; edge list of a 1-vertex hull is `[v,v]`, of a 2-vertex hull the single edge, else the closed loop), `depth = rA+rB-dist`, null if `<=0`; normal = `(pB-pA)/dist` (`(1,0)` when dist 0); single point midway between the two offset surface points; if either hull is a capsule and BOTH segment end vertices penetrate (`d=rr-s>0`, `s` = signed distance along n from the other closest point), report those two end points instead (order = vertex order). If overlapping: `depth=rr-best`, null if `<=0`; normal = face normal (negated when winner is B). Points: when `rr==0` and both hulls have >=3 vertices, Sutherland-style clip of the incident edge (the edge of the incident hull whose outward normal has the smallest dot with the reference normal, first index on ties) against the reference edge's side planes, keeping points with separation `<= EPS`, each at the midpoint between surfaces with `depth=max(0,-sep)`; if clipping yields nothing/<2 points fall to the fallback: the (up to) two other-hull vertices with smallest separation (sorted by separation then vertex index), second dropped if it does not penetrate (`d<=0`) and one already exists, point offset by the radius and half depth, depth `max(d,0)`.
- `overlaps`(a,b) = `collide != null`. `overlapAll`(shape,list) -> ascending indices.
- **distance**(a,b) -> `{distance, overlap, normal, pointA, pointB}`. Overlapping (SAT best<=0 with faces, or `dist-rA-rB<=0`): `distance 0, overlap true, pointA/pointB null`, normal = SAT face normal (negated if from B) or the closest-pair normal. Else `distance = dist-rA-rB`, normal a->b, points = closest points moved by the radii.
- **contains**(shape,x,y) (`containsPoint`): hulls with <3 vertices (circle, capsule): squared distance to the segment/point `<= r^2` (inclusive). Polygon-like: inside iff `dot(p-f.p, n) <= 0` for every face (boundary inclusive).
- **raycast**(shape,ox,oy,dx,dy,maxT=1) -> `{t,x,y,normal,inside}`|null; `p=o+d*t`, d need not be unit, `t in [0,maxT]`. Normal faces the origin. Start inside (`c<=0` for circles; `tmin<0<=tmax` for polys) -> `t 0, inside true, normal=-d/|d|`, point = origin. Circle: `a=0` -> null; `disc<0` null; nearest root `(-b-sqrt(disc))/(2a)`, null if `<0` or `>maxT` (tangent `disc==0` hits). Poly/obb/aabb: slab/half-plane clip over faces (`denom==0` and outside -> null, `denom<0` raises tmin and records the normal with strict `>`), null if `tmin>tmax`, `tmax<0`, `tmin>maxT`, or `|d|==0`. Capsule: three candidates (circle at each end vertex, and the obb `(x,y,hl,r,angle)`); any `inside` candidate is returned immediately in order end0,end1,obb; otherwise smallest `t` (first wins ties). `segmentcast(s,x0,y0,x1,y1) = raycast(..., x1-x0, y1-y0, 1)`. `raycastNearest(list,...)` -> `{index,...hit}`, lowest t, ties lowest index.
- **sweptAABB**(a,dx,dy,b) -> `{t,normal,x,y,overlap}`|null, a moving, b static. Minkowski slab test on `hx=a.hw+b.hw`, `hy`; an axis with zero displacement returns null when `|a.c-b.c| >= h` (touching/parallel misses), otherwise it is unbounded. `entry=max(n0,n1)`, `exit=min(f0,f1)`; null if `entry>=exit || exit<=0 || entry>1`. `entry<0` (already overlapping): `collideAABB(b,a)`, null if none, else `{t:0, normal: that normal, x:a.x, y:a.y, overlap:true}`. Else normal from the axis with larger entry (`n0>n1` -> x axis, ties go to **y**): x-axis `(dx>0?-1:1,0)`, y-axis `(0,dy>0?-1:1)`; point `a+d*entry`.
- **shapeCast**(a,dx,dy,b) -> `{t,normal,x,y,overlap}`|null; conservative advancement, max 128 iterations. Loop: translate a by `d*t`; `collide` hit -> `{t, normal=-m.normal, point=m.points[0], overlap: it===0}`; else `distance`; overlap flag -> `{t, normal=-d.normal, x:at.x,y:at.y, overlap: it===0}`; `closing=d.dot(normal)`; `<=0` -> null (moving away or parallel); `distance<=EPS` -> touching hit at the midpoint of pointA/pointB, `overlap:false`; `t += distance/closing`; `t>1` -> null; falling out of the loop -> null.
- **moveAABB**(a,dx,dy,boxes,iterations=4) -> `{x,y,hits:[{index,t,normal}]}`. Per iteration: stop if remaining motion is `(0,0)`; nearest `sweptAABB` over boxes (strict `<` => lowest index wins ties); none -> apply all, stop; else advance by `t`, record hit, `rem=1-t`, remaining `p=r*rem`, remove the into-surface component only when `dot<0`, continue. Starting box is `aabb(x,y,a.hw,a.hh)` each iteration.
- **hash** (`createSpatialHash(cellSize=32)`: insert(id,bounds,{layer,mask}) [re-insert replaces, gets a new order], update(id,bounds) [keeps order and layer/mask; unknown id throws], remove, clear, has, size, query(bounds), queryPoint, pairs(filter?)). Cell = `floor(coord/cellSize)` per axis (negative coords floor toward -inf), item registered in every cell of its inclusive range. Vector runner order: inserts, then `moves` (update), then `removes`, outputs `{pairs, queries}`. `query` -> ids whose stored bounds overlap (inclusive), deduped, sorted by `cmpId`. `pairs` -> `[[lo,hi]...]` with `cmpId(lo,hi)<=0`, deduped across shared cells, bounds-overlapping, `canCollide`, optional filter, sorted by first then second id. **`cmpId`: numbers before strings; same type compared with `<`/`>` (strings by UTF-16 code unit order, numbers numerically).** Results must never depend on insertion order or hash iteration order.
- **tilemap** (`createTilemap({cols,rows,tileSize,tiles,x=0,y=0,outside=0,oneWayThickness=4})`): row-major `tiles`; out-of-range cells read `outside`. `TILE`: EMPTY 0, SOLID 1, ONEWAY 2, SLOPE_R 3, SLOPE_L 4, SLOPE_R_LO 5, SLOPE_R_HI 6, SLOPE_L_HI 7, SLOPE_L_LO 8. `SLOPES[k] = [left,right]` floor height fractions: 3 `[0,1]`, 4 `[1,0]`, 5 `[0,.5]`, 6 `[.5,1]`, 7 `[1,.5]`, 8 `[.5,0]`. `colliderAt(c,r)`: cell `minX=x+c*ts, minY=y+r*ts`; solid `{kind,minX,minY,maxX,maxY,col,row,tile}`; oneway has `maxY=minY+min(oneWayThickness,ts)`; slope `slope:{x0:minX, y0:maxY-s[0]*ts, x1:maxX, y1:maxY-s[1]*ts}`; unknown kind -> null. `query(b)` iterates cells `floor((b.min-origin)/ts)..floor((b.max-origin)/ts)` inclusive, row-major (r outer, c inner), skipping empty. `tileAt(wx,wy) -> {col,row,kind}`. Vector `tilemap` output: `queries` = collider lists as-is; `shapes` = per shape `collideSource` results reduced to `{col,row,manifold}`.
- **collideSource**(src,shape,opts{layer,mask,prevMaxY}) -> `[{collider,manifold}]` in `src.query(bounds(shape))` order; filter with `canCollide(collider, {layer,mask})`; manifold = `collide(colliderShape(c), shape)` (normal points collider -> shape); a `oneway` collider counts only when `normal.y < -0.5` and `(prevMaxY ?? -Infinity) <= c.minY + 1e-6`. `colliderShape`: non-slope -> aabb of the rect; slope -> polygon at (0,0) with points `(x0,maxY),(x1,maxY),(x1,y1),(x0,y0)`. `surfaceY(c,x)`: non-slope `minY`; slope linear `y0+(y1-y0)*u`, `u` clamped to [0,1].
- Scene `createScene(colliders,{cellSize=32})`: hash over insertion index; `query(b)` returns colliders sorted by insertion index. `fromPlatformerWorld(w,{minX=-10000,maxX=10000,depth=64})`: pits sorted by `x0`; solids `[cur,p.x0]` from `groundY` to `groundY+depth` (only if `p.x0>cur`), `cur=max(cur,p.x1)`; trailing solid to `maxX` if `maxX>cur`; platforms -> `oneway {minX:x-w/2,maxX:x+w/2,minY:y,maxY:y+4,id}`; cellSize 64.

## Edge cases to port exactly
Touching = no contact (collide, sweptAABB parallel); zero-length edges skipped in faces; zero-direction ray returns null (poly) / null (circle `a==0`); degenerate polygon area sign decides winding; capsule with `hl=0` behaves as circle-like 2 coincident vertices (distance/closest handle `l2=0` by `t=0`); `maxT` default 1; `inside` hits ignore `maxT`; tangent circle ray (`disc=0`) hits.

## Determinism
No `Date`/RNG; all tie-breaks are "first index / lower id wins" with strict comparisons as above; keep operation order (float sums are compared at 1e-9 but chained queries amplify drift). Ints/ids exact, ids sort numbers before strings.
